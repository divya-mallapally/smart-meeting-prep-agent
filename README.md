# 🤖 Smart Meeting Prep Agent

An AI-powered agent that helps you prepare for any meeting in minutes. Enter your meeting details, upload documents, and get a complete preparation pack — summary, objectives, questions to ask, talking points, risks, a 5-minute briefing, and action-item follow-up — generated by Google Gemini.

## Problem Statement

People regularly walk into meetings unprepared: they don't review previous notes, miss action items, forget to ask key questions, or skim documents at the last minute. Manual meeting preparation is slow, inconsistent, and often skipped entirely — leading to wasted meeting time and missed decisions.

## Objective

Build a simple AI agent that takes raw meeting information (title, agenda, participants, previous notes, documents) and automatically produces a structured, reliable meeting-preparation pack without inventing information.

## Features

- 📦 **Full Preparation Pack** — 12 structured sections in one click
- ❓ **Question Generation** — smart questions grouped by purpose
- 💬 **Talking Points** — opening, core, and closing points
- ⏱️ **5-Minute Briefing** — read everything essential before you walk in
- ✅ **Action Items** — extracted from previous notes with owners and deadlines
- 📄 **Document Upload** — PDF and TXT files are parsed and included in the analysis
- 🛡️ **Anti-hallucination prompts** — the AI only uses supplied information and clearly says when something is missing
- 🔐 **Secure** — API key stored in `.env`, never in code, never on GitHub

## Technology Used

| Technology | Purpose |
|---|---|
| Python 3.11+ | Programming language |
| Streamlit | Web UI (runs in the browser) |
| Google Gemini API (`google-genai` SDK) | The LLM that generates all content |
| pypdf | Text extraction from PDF files |
| python-dotenv | Loads the API key safely from `.env` |
| Git & GitHub | Version control and hosting |

**Why no LangChain / FAISS?** For a single-model app with short documents, calling Gemini directly and passing extracted text in the prompt is the simplest reliable design. LangChain and vector databases add value only when you chain many models or search large document collections.

## Architecture

```
User
 ↓
Streamlit UI (app.py)          ← forms, buttons, file upload
 ↓
Document Processor             ← PDF/TXT → plain text
(document_processor.py)
 ↓
AI Meeting Agent (agent.py)    ← builds context + safe prompts
 ↓
Prompts (prompts.py)           ← anti-hallucination templates
 ↓
Google Gemini LLM              ← generates the content
 ↓
Structured Markdown results    ← shown in the UI, downloadable
 ↓
User
```

## Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/smart-meeting-prep-agent.git
cd smart-meeting-prep-agent

# 2. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # macOS/Linux
venv\Scripts\activate           # Windows (PowerShell/CMD)

# 3. Install dependencies
pip install -r requirements.txt
```

## Environment Setup

```bash
# 1. Get a free API key: https://aistudio.google.com/apikey
# 2. Copy the example env file
cp .env.example .env            # macOS/Linux
copy .env.example .env          # Windows

# 3. Edit .env and paste your key:
GEMINI_API_KEY=your_actual_api_key_here
```

> ⚠️ `.env` is listed in `.gitignore` and must never be committed to GitHub.

## How to Run

```bash
streamlit run app.py
```

The browser opens automatically at **http://localhost:8501**. If it doesn't, copy the "Local URL" printed in the terminal and paste it into your browser.

## Example Usage

1. **Sidebar** — enter the meeting title, date/time, type, and participants.
2. **Main page** — enter the agenda, description, and previous meeting notes.
3. **Upload** any relevant PDF/TXT documents.
4. Click **🚀 Prepare My Meeting** → the full 12-section pack appears under *Results*.
5. Use the other buttons for questions, talking points, a brief, or action items.
6. Download any result as Markdown with the ⬇️ button.
